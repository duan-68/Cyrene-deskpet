# 桌宠小插件（桌面删除动画桌宠）设计文档

> 日期：2026-08-16
> 状态：待用户审查

## 1. 目标

开发一个 Windows 桌面宠物应用：当用户删除桌面上的软件快捷方式图标时，桌宠（Q 版「昔涟」，坐在弓上）会自动哼着歌晃着双脚漂浮到该图标位置，先把图标"扔进垃圾桶"，再把垃圾桶"踢飞"，让"删除软件"这件事变得形象生动。

**核心体验要求（用户明确）：**
1. 在桌宠执行动作前，图标不能先消失，而是随着桌宠动作的进行自然消失。
2. 删除动作序列固定为：先把软件图标扔进垃圾桶 → 再踢飞。
3. 桌宠素材由用户提供的图片生成。

## 2. 技术栈

| 组件 | 选型 | 用途 |
|------|------|------|
| 语言 | Python 3.12 | 主逻辑 |
| GUI | PySide6-Essentials | 透明无边框置顶窗口、动画渲染 |
| 文件监控 | watchdog | 监控桌面目录的删除事件 |
| Shell 集成 | ctypes（标准库） | 枚举桌面图标坐标（LVM_GETITEMPOSITION） |
| 图标图像 | PySide6 QFileIconProvider | 提取桌面快捷方式图标外观 |
| 图像处理 | Pillow | 生成角色帧 |
| 音效 | winsound（标准库） | 播放动作音效（.wav） |
| 打包 | PyInstaller | 打包成单个 exe |

> 环境说明：本机已具备 Python 3.12 / Node 24 / git；无 .NET SDK（故不选 C#）。

## 3. 整体架构

单进程桌面应用，五个模块协同：

```
┌─────────────────────────────────────────────────────────┐
│                     桌宠应用（Python）                    │
│                                                          │
│  ┌──────────────┐  删除事件   ┌────────────────┐        │
│  │ 文件监控      │──────────▶│  动作调度器      │        │
│  │ (watchdog)   │            │ 事件→动画序列    │        │
│  └──────────────┘            └───────┬────────┘        │
│  ┌──────────────┐  坐标+外观快照     │                 │
│  │ 图标快照      │──────────────────▶│                 │
│  │ (Shell COM)  │                    ▼                 │
│  └──────────────┘            ┌────────────────┐        │
│                              │  桌宠窗口       │        │
│                              │ 透明置顶+动画    │        │
│                              └────────────────┘        │
│  ┌──────────────┐                                      │
│  │  系统托盘     │  退出 / 暂停监控                       │
│  └──────────────┘                                      │
└─────────────────────────────────────────────────────────┘
```

### 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 图标快照 | `icon_snapshot.py` | 定期枚举桌面 `.lnk`，维护「文件名 → 屏幕坐标 + 图标外观」映射 |
| 文件监控 | `file_watcher.py` | watchdog 监听 Desktop 目录，捕获删除事件并过滤 |
| 动作调度 | `dispatcher.py` | 删除事件 → 查快照 → 派发动画序列与音效，维护动作队列 |
| 音效 | `audio.py` | 加载并播放动作音效（扔垃圾桶、踢飞、移动） |
| 桌宠窗口 | `pet_window.py` | 透明置顶窗口，渲染角色动画与图标/垃圾桶飞行动画 |
| 托盘 | `tray.py` | 托盘菜单：退出、暂停/恢复监控 |
| 入口 | `main.py` | 组装各模块，启动事件循环 |

## 4. 核心数据流

1. **启动时 + 每 1 秒**：通过 Shell COM 枚举桌面图标，维护快照表 `{文件名: (屏幕坐标, 图标外观)}`。
2. **用户删除桌面 `.lnk`**（Delete / 拖回收站 / Shift+Delete / 右键删除）→ watchdog 捕获事件。
3. 调度器从**删除前的快照**取出该图标的坐标与外观（删除后图标已消失，必须提前维护快照）。
4. 桌宠窗口在原坐标处**顶替显示图标外观**（图标看起来还在）。
5. 播放动画序列：角色哼着歌晃着双脚漂浮到图标旁 → 图标飞向回收站（扔垃圾桶）→ 垃圾桶飞出屏幕（踢飞）→ 角色回到待机（待机时晃着双脚哼着歌）。

## 5. 关键难点与对策

| 难点 | 对策 |
|------|------|
| 图标删除后就查不到位置 | 删除前持续维护坐标 + 外观快照表 |
| 拖进回收站可能报 `moved` 而非 `deleted` | 同时监听 `deleted` 与 `moved`（目标为回收站）两类事件 |
| 多显示器 / DPI 缩放坐标偏移 | 统一换算到虚拟屏幕坐标系，用 `GetDpiForWindow` 校正 |
| 桌面图标枚举有 Windows 版本差异 | 主方案 Shell COM（`IShellFolder`+`IFolderView`），失败降级为 `LVM_GETITEMPOSITION` 消息方案 |
| 图标不能先消失（系统行为限制） | **缓存顶替法**：删除瞬间（约 50–150ms 内）用缓存图标外观顶替在原位置，随动作自然消失 |

### 缓存顶替法说明

Windows 下用户删除图标后，Explorer 会立即移除桌面图标（系统行为，无法拦截）。本方案通过"预先缓存图标外观 + 删除瞬间立即顶替显示"实现视觉上的"图标不先消失"：

- 图标外观缓存：图标图像（Shell 提取，透明背景）+ 文件名文字标签。
- 删除事件触发后，立即把缓存外观绘制在桌宠窗口的对应位置（顶替）。
- 该外观随「扔垃圾桶 → 踢飞」动画移动、缩小、淡出，实现自然消失。
- 间隙约 50–150ms（约 3–9 帧），肉眼基本无感。

## 6. 素材方案

### 6.1 输入素材

用户提供已抠图素材：`R-C.png`
- 尺寸 1200×675，RGBA，透明背景（用户已抠好）。
- 角色：游戏《崩坏：星穹铁道》角色「昔涟」的 Q 版形象，坐在一个弓上（坐姿，横向构图）。

### 6.2 素材处理流程

1. **素材已抠好**：用户提供的 `R-C.png` 已带透明背景，直接使用。
2. **生成简单帧**（程序化，Pillow）：
   - `idle` 待机：坐姿原图 + 轻微上下浮动 + 小幅左右摇摆（模拟晃着双脚、哼歌）。
   - `move` 移动：坐姿原图整体平移 + 上下浮动 + 摇摆（坐姿角色漂浮移动）。
   - `act` 动作示意：坐姿原图做小幅下压/上挑位移（配合图标飞行动画）。
3. **删除动作**：不依赖角色复杂肢体动画，而是**图标与垃圾桶的运动动画**（见第 7 节）。
### 6.3 音效素材

| 音效 | 触发时机 | 建议素材 |
|------|---------|---------|
| 移动 | 角色移动到图标旁 | 轻快短音（可选） |
| 扔垃圾桶 | 图标飞向回收站 | "咚/噗" 短音 |
| 踢飞 | 垃圾桶飞出屏幕 | "咻/啪" 短音 |

- 来源：免费音效库（freesound.org、pixabay、mixkit 等），或用户自行提供。
- 格式：`.wav`（QSoundEffect 原生支持，低延迟）。
- 音效可静音，由托盘菜单开关。

> 版权提示：昔涟为《崩坏：星穹铁道》游戏角色，本素材仅供用户个人自用，不涉及商业分发。

## 7. 动画序列设计

删除一个图标时，桌宠窗口按以下阶段播放（用户已确认的「先扔垃圾桶 → 再踢飞」）：

| 阶段 | 时长（约） | 表现 | 音效 |
|------|-----------|------|------|
| 1. 顶替 | 即时 | 缓存图标外观绘制在原坐标，图标"看起来还在" | — |
| 2. 移动 | 0.5–1.0s | 角色（坐弓）平移到图标旁，播放 `move` 帧 | 轻快短音（可选） |
| 3. 扔进垃圾桶 | 0.5s | 图标外观沿抛物线飞向桌面回收站图标位置，缩小 + 旋转 + 淡出 | "咚/噗" 短音 |
| 4. 踢飞 | 0.5s | 垃圾桶沿弧线快速飞出屏幕，位移 + 旋转 + 淡出 | "咻/啪" 短音 |
| 5. 归位 | 即时 | 角色回到待机 `idle` 帧 | — |

- 回收站位置通过 Shell COM 一并枚举（桌面命名空间项）。
- 若枚举不到回收站，降级为"图标向屏幕右下角飞出"。

## 8. 异常处理

| 场景 | 处理 |
|------|------|
| 快照中找不到被删图标 | 跳过动画，不报错 |
| 图标枚举 / COM 调用失败 | 记录日志，降级 ListView 消息方案，仍失败则静默 |
| 窗口被其他窗口遮挡 | 窗口设 `WindowStaysOnTopHint` 置顶 |
| 多个图标快速连续删除 | 动作入队列，逐个播放，超出队列上限丢弃最旧 |
| 桌面目录不可读 / 权限不足 | 托盘提示，暂停监控 |

## 9. 测试策略

| 类型 | 内容 |
|------|------|
| 单元测试 | 快照解析、事件过滤（deleted/moved）、坐标换算、动作队列 |
| 集成测试 | watchdog 事件 → 调度器 → 窗口调用链（mock 窗口） |
| 手动测试 | 实际删除桌面图标，观察顶替时机、移动、扔垃圾桶、踢飞全流程 |
| 边界测试 | 多显示器、DPI 缩放、连续删除、回收站枚举失败 |

## 10. MVP 范围

**第一版交付：**
1. 透明置顶桌宠窗口，播放待机 / 移动动画。
2. 监控桌面 `.lnk` 删除事件（含拖回收站）。
3. 图标坐标 + 外观快照维护。
4. 删除触发完整动画序列（顶替 → 移动 → 扔垃圾桶 → 踢飞）+ 同步音效。
5. 系统托盘（退出、暂停/恢复监控、音效开关）。
6. PyInstaller 打包成单个 exe。

**非 MVP（后续迭代）：**
- 多角色切换。
- 设置界面（动画速度、动作开关）。
- 扩展到「卸载程序（控制面板）」场景。
- AI 生成复杂角色肢体动作帧。
